# Работа с Pif-Paf

[English](AGENTS.md) | [Русский](AGENTS.ru.md)

Сначала прочитайте [README.ru.md](README.ru.md) и [docs/architecture.ru.md](docs/architecture.ru.md). Это самостоятельная игра на Cloudflare Workers. Не добавляйте личные домены, account IDs, списки людей, токены или реальные фото в исходники и примеры.

## Команды

- `npm ci` — установка закреплённых зависимостей.
- `npm run check` — lint, TypeScript, unit-тесты, сборка.
- `npm run test:integration` — сквозные HTTP-тесты с отдельной локальной D1/R2, без production-доступа и API-ключа.
- `npm run lint` — дополнительная проверка при изменении интерфейса.
- `npm run audit:export` — эвристическая проверка tracked-файлов перед распространением.

Никогда не запускайте `deploy`, `db:migrate:remote`, удаление ресурсов или публикацию GitHub только ради проверки кода. Это отдельные действия по запросу владельца.

## Игровая механика

- Все активные игроки — один направленный цикл независимо от группы.
- При выбытии предшественник наследует цель выбывшего; последний игрок имеет `target_id = NULL`.
- HTTP-клиент получает только свою цель. Не отдавайте скрытые связи в обычном `/api/state`.
- Любое изменение состава, целей или стадии с изменением ревизии должно использовать `mutationGuard(revision)` первой операцией атомарного D1 batch. При регистрации учитывайте гонку с жеребьёвкой.
- Проверяйте одновременные действия, повторный запрос, финал из двух игроков и откат.
- Возврат к регистрации/перезапуск очищают историю раунда; не меняйте это молча.

## Настройки и UI

- Новые параметры задавайте в `lib/settings.ts`, валидируйте сервером и отражайте в админке и документации.
- Не зашивайте конкретное количество групп; пустой список — допустимый рабочий режим.
- Группы не являются командами с отдельными условиями победы.
- Сохраняйте mobile-first интерфейс, загрузку фото с камеры и `prefers-reduced-motion`.
- Новые темы не должны менять неизменяемые правила цикла.

## Газета

AI необязателен. Любая недоступность API должна сохранять игру и возможность прочитать шаблонную заметку. Не вызывайте платный API в тестах.

Не раскрывайте убийцу, текущую цель и свидетелей в статьях до финала. Показания и редакторские строки — недоверенные данные. Не включайте API-ключ или Authorization в диагностический JSON. Диагностика доступна только организатору.

Отложенная публикация основана на `publish_at`; не возвращайте Cron или webhook без отдельного продуктового запроса.

## Схема

`drizzle/0000_*.sql` — начальная схема новой установки. После выпуска добавляйте новые миграции; не переписывайте применённую схему и не добавляйте разовые правки конкретной игры в миграции.

Секрет `PLAYER_AUTH_SECRET` должен переживать деплои. Не объединяйте его с паролем организатора. Новые установки не поддерживают автоматический перенос исторических частных баз.
