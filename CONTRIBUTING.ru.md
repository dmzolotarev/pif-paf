# Изменения проекта

[English](CONTRIBUTING.md) | [Русский](CONTRIBUTING.ru.md)

Обсудите изменение механики до большого рефакторинга. В описании изменения объясните наблюдаемое поведение, причину и проверку.

Перед отправкой выполните `npm run check` и `npm run test:integration`. Для изменений UI проверьте узкий экран, клавиатуру и уменьшенное движение. Новые правила цикла покрывайте сценариями, включая одновременные действия.

Используйте вымышленные данные. Не прикладывайте базы, фотографии участников, API-ключи или неочищенные снимки диагностики. `.dev.vars`, `.env*`, `.wrangler/` и build output остаются локальными.

Новые настройки должны быть доступны организатору и описаны в документации. Сохраняйте возможность играть без AI и без групп.

Инструкция для coding-агентов — [AGENTS.ru.md](AGENTS.ru.md). Обновляйте английскую и русскую версии документации вместе и сохраняйте ссылки переключения языка.
