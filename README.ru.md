# Pif-Paf

[English](README.md) | [Русский](README.ru.md)

Мобильная веб-игра «Киллер» для компании знакомых. Каждый охотится за одним человеком и одновременно является чьей-то целью. Выбывший подтверждает событие на сайте, цикл перестраивается, а газета рассказывает историю игры.

Интерфейс игры сейчас на русском; документация доступна на английском и русском.

Проект рассчитан на один приватный игровой состав на одну установку. Название, группы, роли и газетную тематику организатор настраивает через админку. По умолчанию групп нет. Работает без AI, webhook и планировщика.

## Возможности

- Самостоятельная регистрация по общему коду или общей ссылке без кода; необязательная предзагрузка имён.
- Имя, фото из галереи или камеры, необязательная группа, роль из списка или свой тег; феминитивы.
- Личный четырёхзначный PIN, запоминающая вход cookie, временная блокировка после неверных попыток и сброс PIN организатором.
- Одна случайная замкнутая цепочка из всех зарегистрированных игроков. Минимум три человека для старта.
- Два варианта правил: свидетель выводит киллера из игры либо только отменяет попытку.
- Секретная цель с фотографией, скрываемая обложкой; участники, статусы и туман войны.
- Подтверждение выбытия в два шага; новая цель передаётся сразу. Показания отправляются отдельно, без ожидания генерации статьи.
- Газета с задержкой публикации, случайными форматами, шаблонными заметками или необязательным AI-журналистом.
- Редактор промптов, тематик, форматов и ролей; предпросмотр, ручная правка, одобрение, снятие и перегенерация статей. Админская диагностика запросов и ответов модели.
- Пауза, продолжение, исключение участников, отмена последнего выбытия, новая жеребьёвка и возврат к регистрации.
- Автоматическая победа последнего игрока или ручной финал с выбранными победителями; хронология и статистика после завершения.
- Две лёгкие CSS-пасхалки в правилах; их можно отключить. Учтён `prefers-reduced-motion`.

## Быстрый локальный запуск

Нужен Node.js **22.18+** и npm. Авторизация Cloudflare для локальной игры не требуется.

```sh
npm ci
npm run secrets:generate
npm run db:migrate
npm run dev
```

Откройте адрес, который напечатал dev-сервер (обычно `http://localhost:3000`). В `/admin` введите `ORGANIZER_SECRET` из локального файла `.dev.vars`. Скрипт генерирует два независимых секрета и сохраняет существующий файл без изменений.

В админке задайте мероприятие, сохраните настройки, скопируйте общую ссылку и код игры. Участники заполняют профили; после этого проведите жеребьёвку. Для теста нескольких игроков используйте разные браузерные профили.

## Развёртывание

Поддерживаемый вариант — **Cloudflare Workers + D1 + R2**. У каждого владельца свой аккаунт, база, хранилище фотографий и секреты.

[Пошаговая инструкция хостинга](docs/hosting.ru.md) описывает создание ресурсов, миграции, production-секреты, домен, резервные копии и отключение. Внешние API для базовой игры не нужны.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Локальное приложение с локальными D1/R2 |
| `npm run db:migrate` | Миграции локальной базы |
| `npm run db:migrate:remote` | Миграции базы в вашем Cloudflare-аккаунте |
| `npm run build` | Production-сборка |
| `npm run deploy` | Сборка и публикация Worker |
| `npm run typecheck` | TypeScript |
| `npm test` | Механика цикла, настройки, схема базы, статистика и цитаты |
| `npm run test:integration` | HTTP-сценарии на отдельной временной локальной базе |
| `npm run check` | Lint, TypeScript, unit-тесты и сборка |
| `npm run audit:export` | Поиск типичных секретов и личных deployment-файлов в tracked-файлах |

Тесты не требуют API-ключа и не отправляют платные запросы. Интеграционные тесты создают свои локальные ресурсы. Команды проверки сами ничего не публикуют.

## Границы проекта

Это игра на доверии для знакомых. Сайт фиксирует подтверждения, а не доказывает реальное происшествие. Общий код ограничивает регистрацию; имена и фото готовых профилей доступны на экране повторного входа. Не используйте это как систему хранения закрытых персональных данных.

Начальная миграция предназначена для **новой пустой базы**. Автоматического импорта баз от прежних частных установок нет. Не применяйте новую начальную схему поверх существующей игры.
