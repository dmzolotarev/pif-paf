# Настройки и расширение

[English](configuration.md) | [Русский](configuration.ru.md)

## Настройки мероприятия

Они хранятся в `games.settings_json`, проверяются сервером и доступны в админке до старта. `lib/settings.ts` содержит тип, нейтральные значения по умолчанию и валидацию.

| Поле | Назначение |
| --- | --- |
| `title`, `newspaperTitle`, `tagline` | Название игры, газеты и слоган |
| `setting` | Контекст мероприятия для журналиста |
| `timezone` | Часовой пояс IANA для итогов; данные хранятся в UTC |
| `groupLabel`, `groups` | Подпись и список групп; `[]` отключает группировку |
| `safetyRules` | Фразы внутри пункта о безопасном моменте |
| `publicationDelayMin`, `publicationDelayMax` | Случайная задержка 0–1440 минут; равные значения дают фиксированную задержку |
| `fogThreshold` | Автоматический туман при таком или меньшем числе активных игроков |
| `approveDuringFog` | Новые статьи в тумане требуют одобрения |
| `easterEggs` | Визуальные пасхалки |

Импорт JSON в админке заполняет редактор; затем нажмите «Сохранить». Пример: `examples/nautical.json`. Группы задавайте до регистрации: удалять/переименовывать используемую группу нельзя. Пустой список групп снимает группировку.

Модель, промпты, роли и переключатели самой игры сохраняются отдельно от этого JSON. Секреты никогда не являются частью импортируемой темы.

## Авторизация и секреты

`ORGANIZER_SECRET` — пароль админки. `PLAYER_AUTH_SECRET` — независимый ключ для подписи сессий и вычисления солёных PIN-хешей. Общий код игры генерируется при первой загрузке пустой базы и меняется в админке.

На том же устройстве сайт использует HttpOnly cookie. После очистки браузера участник выбирает профиль и вводит PIN. После пяти неудачных попыток профиль блокируется на 15 минут; организатор может сбросить PIN. Ограничение относится к профилю, а не ко всей установке.

## AI-журналист

Без `OPENAI_API_KEY` или без выбранной модели используются шаблоны. Для AI задайте ключ в секретах Worker и укажите доступный вашему API-проекту ID модели с поддержкой Responses API и JSON Schema Structured Outputs.

Не храните ключ в исходниках или публичных переменных фронтенда. Для `reasoning.effort` выберите допустимое значение своей модели; `default` совсем не передаёт этот параметр. Ошибка API приводит к шаблонной заметке и объяснению в диагностике.

Промпт состоит из независимых частей: фильтр скрытых игровых данных, основная редакторская инструкция, название и контекст мероприятия, тематика, случайный формат, обработка показаний, работа с тегом и дополнительные указания организатора.

Творческие части доступны в админке. Короткий фильтр нераскрытия убийцы/цели остаётся в коде; пользовательские показания помечаются как недоверенный материал. Другие имена маскируются до генерации и проверяются в результате. Это практические ограничения для дружеской игры, а не гарантия защиты от любых подсказок.

Роли, тематики, режимы показаний и форматы можно добавлять и удалять. У каждого элемента стабильный уникальный ключ. Для каждой причины выбытия должен оставаться хотя бы один формат. Удалённый формат не стирает уже написанные статьи.

Ключ API не входит в диагностику. Записываются текст запроса, ответ API, разобранная статья и причина fallback. Учитывайте это при резервном копировании и публикации скриншотов админки.

Официальная справка: [Responses API](https://developers.openai.com/api/docs/guides/responses), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [reasoning](https://developers.openai.com/api/docs/guides/reasoning).
